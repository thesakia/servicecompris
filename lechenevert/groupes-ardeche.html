Groupes

Un point de chute chaleureux pour explorer l'Ardèche ensemble

Randonneurs, motards, cyclistes, voitures anciennes, associations : la maison sait organiser l'hébergement, les repas et les départs d'activités.

Accueil groupe

Une organisation simple, une vraie maison à l'arrivée

Le Chêne Vert accueille des groupes jusqu'à 60 personnes, avec chambres doubles, triples, quadruples, parking gratuit, local vélo et possibilité de repas adaptés. C'est une base pratique pour rayonner vers Largentière, Aubenas, les gorges, les villages de caractère et les routes d'Ardèche.

L'équipe garde le sens de l'accueil hôtelier : préparer les arrivées, fluidifier les repas, conseiller les circuits, adapter les horaires quand c'est possible et faire en sorte que le groupe profite du séjour sans complication.
